# Возможности и средства применения искусственного интеллекта в разработке мультимедиа-продуктов

Учебно-исследовательский проект. Итог — интерактивный многостраничный сайт-исследование на русском языке.

## Структура репозитория

| Путь | Что это |
|------|---------|
| `PLAN.md` | Дорожная карта проекта, цели, статус этапов |
| `docs/topic-plan.md` | **План затрагиваемых тем** (8 разделов) с привязкой к страницам сайта |
| `docs/website-blueprint.md` | Архитектура сайта: стек, дерево страниц, компоненты, модель данных `Tool` |
| `docs/research/overview.md` | Методология ресёрча и сводка |
| `docs/research/international.md` | Ресёрч: международные сервисы (OpenAI, Google, Midjourney, Runway, Suno…) |
| `docs/research/russia.md` | Ресёрч: российские сервисы (GigaChat, Kandinsky, Шедеврум, YandexGPT…) |
| `docs/research/china.md` | Ресёрч: китайские сервисы (DeepSeek, Qwen, Kling, Seedance, Hailuo…) |
| `docs/research/opensource.md` | Ресёрч: open-source стек для локального запуска (ComfyUI, Wan, ACE-Step…) |
| `docs/research/comparison.md` | Сводные сравнительные таблицы по категориям |

React + TypeScript + Vite · Tailwind CSS · shadcn/ui · Magic UI · React Bits · Lucide Icons
