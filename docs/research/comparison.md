## Рекомендованные связки (для кейсов на сайте)

**A. Бесплатный русский стек (без VPN, рубли):**
GigaChat (сценарий + видео со звуком) → Kandinsky 6.0 / Шедеврум (визуал) → SaluteSpeech/SpeechKit (озвучка) → ERA2 Music (песня) → CapCut (монтаж).

**B. Мировой топ-качество:**
GPT-6 / Gemini 3 (сценарий) → Midjourney V8 (визуал) → Veo 3.1 / Kling 4.0 (видео) → Suno v6 (музыка) → ElevenLabs v3 (речь) → HeyGen (аватар) → Descript (монтаж).

**C. Китайский экономный стек:**
DeepSeek V4 / Qwen 3.8 (сценарий) → Qwen-Image 3.0 / Seedream 5.0 (визуал) → Seedance 2.5 / Hailuo H3 (видео) → MiniMax Music 3 (музыка) → MiniMax Audio (речь) → Tripo (3D).

**D. Локальный open-source (приватно, бесплатно, автономно):**
Qwen3.8-27B в Ollama (текст) → ComfyUI + FLUX/Wan 2.2 (изображения и видео) → ACE-Step 1.5 (музыка) → Chatterbox/F5-TTS + Whisper (речь/субтитры) → Hunyuan3D (3D).
