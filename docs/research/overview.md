# Обзор ресёрча: методология и главные выводы

> Дата проверки данных: **2026-11-06**. Все версии, цены и факты зафиксированы на эту дату.

## Методология

1. **Источники:** веб-поиск (русскоязычный и англоязычный), официальные сайты и документация, changelog разработчиков, деловые СМИ (РБК, Forbes, Reuters, TechCrunch), отраслевые обзоры (vc.ru, Habr, Т—Ж, Яндекс Практикум).
2. **Инструмент:** три параллельных направления исследования (РФ / Китай / мир + open-source) с проверкой актуальных версий через поиск, а не по памяти модели.
3. **Критерии отбора инструментов:** качество результатов, скорость, цена, доступность из России, лицензия (можно ли в коммерческий продукт), наличие API, зрелость.
4. **Формат фиксации:** единые карточки по схеме `Tool` из [website-blueprint.md](../website-blueprint.md) — ресёрч напрямую переносится в каталог сайта.
5. Неподтверждённые официально данные помечены «по последним доступным данным» (\*).

## Главные выводы (ноябрь 2026)

1. **Видео — самая горячая категория.** OpenAI закрыла Sora (весна–осень 2026); лидерство оспаривают Google Veo 3.1, китайские Kling 4.0 и Seedance 2.5, западный Runway Gen-4.5. Тренд — звук «по умолчанию» и мультишотность.
2. **Китай — второй центр генеративного ИИ.** Доминирует в открытых весах (Wan 2.2, Qwen-Image 3.0, HunyuanImage 3.0, ACE-Step 1.5) и теснит Запад в потребительских сервисах, часто дешевле. Из РФ — самый доступный «зарубежный» вариант: Qwen и DeepSeek работают без VPN, Kimi принимает карты «Мир».
3. **Россия — зрелый «текст и изображения», догоняющее «видео».** GigaChat генерирует видео со звуком Full HD бесплатно, Kandinsky 6.0 — без лимитов. Полный русский стек существует и работает в рублях без VPN; слабые места — музыка (локализованные Suno-обёртки) и сложные видеосцены.
4. **Музыка пережила «лицензионный перелом»:** Suno v6 обучена на лицензионной музыке (Warner, BMG, Believe), Udio свернулась; в open-source лидер — ACE-Step 1.5 (MIT, Китай).
5. **Агентизация — главный тренд во всех регионах:** Алиса AI с пользовательскими агентами, GigaChain + Deep Agents, Cotype Pro 2.5, Pika как мульти-модельный хаб.
6. **Open-source стал продакшен-альтернативой:** Wan 2.2 (Apache 2.0) для коммерческого видео, ACE-Step для музыки, Chatterbox/Whisper для речи, ComfyUI — стандартная среда. Для РФ — единственный безбарьерный путь (нет оплаты и блокировок).
7. **Доступность из РФ — трёхслойная:** российские сервисы (без барьеров) → китайские (в основном доступны, оплата через «Мир»/посредников) → западные (VPN + виртуальные карты; исключения без VPN — Suno, CapCut).

## Как это ложится на сайт

- Каталог `/tools/*` собирается из карточек этих файлов → `src/data/tools.ts` (схема в blueprint).
- Таблицы `/comparison` берутся из [comparison.md](comparison.md).
- Кейсы `/cases` строятся на выводах: русскоязычный бесплатный стек (GigaChat + Kandinsky + SaluteSpeech) vs мировой топ (Veo 3.1, Kling 4.0, Suno v6) vs локальный open-source (ComfyUI + Wan 2.2 + ACE-Step).
- Раздел «Этика» опирается на обнаруженный «лицензионный перелом» в музыке и требования маркировки ИИ-контента в РФ.
