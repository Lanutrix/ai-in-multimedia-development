# План проекта

**Тема:** «Возможности и средства применения искусственного интеллекта в разработке мультимедиа-продуктов»

**Дата старта:** 2026-11-06

**Финальный продукт:** интерактивный многостраничный сайт-исследование на русском языке.

---

## Цели

1. Систематизировать возможности генеративного ИИ на каждом этапе разработки мультимедиа-продукта (от идеи до локализации).
2. Составить актуальный каталог инструментов с особым вниманием к **российским** и **китайским** сервисам.
3. Показать инструменты в действии: сравнительные кейсы и сквозной пайплайн создания мультимедиа-продукта.
4. Оформить результат в виде адаптивного сайта с современной анимацией.

## Технологический стек сайта (фиксировано)

- **Tailwind CSS** — стилизация, адаптивная вёрстка
- **shadcn/ui** — кнопки, вкладки, карточки, таблицы, аккордеоны
- **Magic UI** — анимированные фоны и визуальные эффекты
- **React Bits** — анимации текста и интерактивные элементы
- **Lucide Icons** — единый стиль иконок
- База: **React + TypeScript + Vite**, роутинг — react-router (см. [docs/website-blueprint.md](docs/website-blueprint.md))

## Принятые решения и соглашения

- Контент сайта и вся документация — **на русском языке**.
- Ресёрч хранится в Markdown: один файл на регион + сводные таблицы. Сайт позже «питается» этими данными (каталог инструментов → типизированный `src/data/tools.ts`).
- Схема карточки инструмента зафиксирована в blueprint — ресёрч ведётся сразу по ней, чтобы потом не переписывать.
- Данные ресёрча снабжаются датой проверки и ссылками на источники (важно для учебного проекта).

## Риски и открытые вопросы

- Доступность зарубежных сервисов из РФ меняется — в ресёрче фиксируем состояние на дату проверки, сайт будет брать данные из `tools.ts` (легко обновить).
- У китайских сервисов важно отличать внутреннюю (кит.) и международную версии (например, у Kling, Hailuo, Qwen) — фиксируем обе.
- Цены подписок проверены на дату ресёрча; на сайте помечаем «цены на 11.2026».
